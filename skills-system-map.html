Skill Quick Reference

Each skill description is intentionally capped to two lines.

git-sync-features

Rebase all active feature branches onto dev before starting work.

dt-plan

Turn a project idea into a sectioned, critique-ready planning draft.

dt-visualize-plan

Render a plan into reviewable HTML with milestones and flow visuals.

dt-prototype

Build quick logic or UI prototypes to resolve unclear design choices.

dt-review

Run adversarial design critique rounds until the plan is shippable.

dt-visualize-design

Render design-final with section diffs and a browser-friendly summary.

dt-roadmap

Convert finalized design into a contract-grade roadmap and milestones.

dt-build

Execute the validated roadmap end-to-end with verification and commits.

git-merge-feature

Land a finished feature branch to dev and clean up the branch.

dt-writing-draft

Build a publishable long-form draft from notes, sources, and structure.

dt-writing-edit

Tighten a finished draft for structure, clarity, and factual consistency.

dt-handoff

Package current state into a compact, paste-ready next-session prompt.

dt-session-audit

Capture missed decisions/preferences and route them to memory files.

dt-memory-hygiene

Compact bloated memory/governance files without changing intent.

dt-tune

Propose approval-gated SKILL.md amendments based on session friction.
