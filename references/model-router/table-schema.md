# Model router table schema (version 1)

The JSON root contains `schema_version` (integer `1`), `generated_at` (ISO 8601 date or timestamp), `source` (`seed` or `research`), `coverage` (`partial` or `full`), `evidence_routing_approved` (Boolean, initially false), `approved_picks` (array of the last approved category/lane/protected picks), and `categories` (object). Seed tables have partial coverage. A research table has full coverage only after an `-All` research pass successfully profiles every model in the table's scope; a partial rebuild over a partial or seed table remains partial. A partial rebuild over an already full table retains full coverage. The resolver uses bridge picks unless `source=research`, `coverage=full`, and `evidence_routing_approved=true`; a single-model research run does not end bridge mode. Every fixed category has its fixed lane(s): `image-generation` has only `codex`; all others have `codex` and `claude`. A lane contains `fallback` (model ID) and `candidates` (array). The fallback is the strongest non-frontier model of that lane and appears among its candidates.

Each candidate contains `model` (unique nonempty ID in its lane), `frontier` (Boolean), `strength_rank` (positive integer, unique per category/lane; 1 is strongest), raw latest `grade` and `confirmed_grade` (each `strong`, `capable`, `weak`, or `unknown`), `citations` (array), `est_burn` (nonnegative number or null), `est_seconds` (nonnegative number or null), `pass_rate` (number from 0 to 1 or null), and `pass_samples` (nonnegative integer). Each citation has `source` and `url` (nonempty strings), `independent` (Boolean), and `note` (string). `confirmed_grade` is the shared grade of the two newest timestamped history profiles when each has an independent citation for that category; otherwise it is `unknown`. Research saves each accepted profile in `profiles/history` without overwriting earlier runs. Only confirmed strong/capable candidates can challenge a bridge incumbent.

The bridge pick is the incumbent, including the protected bridge pick for protected work and long-form writing. An unknown confirmed grade for the incumbent keeps it in place. A challenger must be non-frontier and at least as highly confirmed; it can replace the incumbent only with a strictly higher grade or, on equal grade, lower calibrated expected cost. An older generation from the same vendor needs a strictly higher grade even if cheaper. Rebuilds retain approval when the evidence picks still match `approved_picks`; any changed category/lane/protected pick clears approval and queues `router-picks-changed-needs-approval`. Run `approve-router-table.ps1 -Show` to inspect old and new picks, `-Approve` to save the snapshot and enable evidence routing, or `-Revoke` to return to bridge picks.

`est_burn` is relative subscription-quota burn per task, not dollars. When it is null, the resolver retains strength-rank order until calibrated. When `pass_samples` is at least 10 and `pass_rate` is present, failure probability is `1 - pass_rate`; otherwise it is 0.10 for strong and 0.25 for capable. Expected cost includes own burn, first-failure retry burn on the next stronger eligible candidate, and two-failure fix burn on the strongest eligible candidate. The strongest candidate has no stronger retry, so its cost is own burn only, plus a first-failure fix term only if a stronger eligible frontier model exists. Rank by expected cost; only candidates within 10% of the minimum expected cost form a tie group. Within that group, lower `est_seconds` wins when both times are known; otherwise lower `strength_rank` wins. Repeat from the remaining minimum for later ranks.

`Test-RouterTable` returns named validation errors and accepts ISO date or timestamp strings and PowerShell DateTime values. `Read-RouterTable` accepts a live table only if it passes validation; otherwise it loads this repository's seed table and returns the validation error. The seed raises one `router-seed-table-in-use` alert in place of per-category no-eligible alerts. Invalid live data also raises `router-live-table-invalid`. Research tables raise `no-eligible:<category>:<lane>` when a lane uses its fallback. An unselectable Codex fallback is returned with a `fallback_unselectable` alert. Image-generation is advisory, bypasses the Codex chat catalog, and seeds only `gpt-image-2`. The table does not execute citation content. Framework dimension contract state for this build is `provisional`.
